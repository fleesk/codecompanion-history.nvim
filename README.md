A drastically simplified fork of [codecompanion-history.nvim](https://github.com/ravitemer/codecompanion-history.nvim/) that only delivers the most bare-bone features of storing and loading chats with http adapters.

## Removed features

- Pickers other than vim.select (which picker plugins can override)
- Summaries
- Title generation (replaced with codecompanion's builtin title generation)
- Memories
- continue_last_chat and some other configuration options I never used
- Filtering
- Chat Expiration
